# diagrams/ —— 图放哪

## 约定：默认不在这里放图

本项目的所有图都**以 Mermaid 代码块的形式写在 markdown 里**，位置：

| 图 | 在哪 |
|---|---|
| 领域模型（ER 图） | `docs/design/02-domain.md` |
| 登录 / 配表 / 渲染 / 增删改 的时序图 | `docs/design/03-flows.md` |
| 状态迁移 | `docs/design/04-states.md`（表格） |
| 权限矩阵 / 类型映射 | `docs/design/05-rules.md`（决策表） |
| 部署拓扑 | `DEPLOY.md` 第 0 节（文字 + 表格） |

## 为什么不导出图片

| 图片文件 | Mermaid 写在 md 里 |
|---|---|
| 需要打开图片才能看 | 文本，diff 里能看出"改了一条线" |
| 无法搜索 | 能 `grep` |
| AI 只能"看"不能逐字读 | 逐字可读、可核对 |
| 容易过期（改了代码没人重画） | 和代码同一次提交里改 |

## 什么时候可以放文件

只有这两种情况：

1. **Mermaid 表达不了的图**（超复杂拓扑、带大量图标的设计稿）→ 用 D2 或 PlantUML，放这里
2. **需要给人看的汇报图**（PPT 用的）→ 放这里，但**不能作为唯一真相**

放文件时命名规则：`<序号>-<内容>.<格式>`，例如 `01-deploy-topology.d2`，
并在文件头注释里写清"生成方式"和"对应哪份文档"。
