# 04 状态与状态迁移

> 状态机是最容易被漏掉的规格：**谁能改状态、改完还能不能改回来、非法迁移怎么办**。
> 这里把系统里所有有状态的实体列清楚。

## 1. 子系统（sys_system.status）

| 状态 | 值  | 含义                                                                      |
| ---- | --- | ------------------------------------------------------------------------- |
| 启用 | `1` | 子系统正常可用，用户可以登录                                              |
| 停用 | `0` | 该子系统用户登录会被拒绝（`ForbiddenException`），已有 token 仍可用到过期 |

| 从   | 事件           | 到     | 前置条件 | 失败处理                                                  |
| ---- | -------------- | ------ | -------- | --------------------------------------------------------- |
| 启用 | 超管点「停用」 | 停用   | 非主系统 | 主系统不允许停用（参数允许但业务上不提交）                |
| 停用 | 超管点「启用」 | 启用   | —        | —                                                         |
| 任意 | 超管删除       | 不存在 | 非主系统 | 主系统返回 400；连带删除用户/角色/路由/配置并 DROP 物理表 |

**注意**：停用只拦「新登录」，已经签发的 token 在 8 小时内仍然有效。
如果要求「停用立刻踢下线」，需要改成每次请求查库校验用户/系统状态（性能代价见 `06-failure.md`）。

## 2. 用户（sys_user.status）

| 状态 | 值  | 说明                                |
| ---- | --- | ----------------------------------- |
| 启用 | `1` | 可登录                              |
| 停用 | `0` | 登录被拒；已签发 token 仍有效到过期 |

| 从   | 事件       | 到     | 前置条件                                        |
| ---- | ---------- | ------ | ----------------------------------------------- |
| 启用 | 管理员停用 | 停用   | 不能停用自己（业务上由前端限制，后端未强制）    |
| 停用 | 管理员启用 | 启用   | —                                               |
| 任意 | 删除       | 不存在 | 不能删除自己（后端强制：`user.service.remove`） |

## 3. 表格配置生命周期（sys_table_config）

```
[不存在]
   │ POST /api/table-configs（校验字段 → 生成 TCID → CREATE TABLE → 插入配置）
   ▼
[已创建] ──PUT（加字段 = ADD COLUMN）──▶ [已创建（字段更多）]
   │
   │ DELETE（DROP TABLE + 删配置）
   ▼
[不存在]（数据不可恢复）
```

| 状态   | 前端表现                      | 可做的操作                           |
| ------ | ----------------------------- | ------------------------------------ |
| 不存在 | 路由指向它时报「TCID 不存在」 | 新建                                 |
| 已创建 | `<Table>` 正常渲染            | 查询、增删改（按权限）、改配置、预览 |
| 已删除 | 指向它的路由变成错误页        | 只能重新配置并更新路由的 TCID        |

**没有「草稿」状态**：创建成功即生效（先建表再写配置，失败会回滚）。

## 4. 业务数据行（biz\_&lt;tcid&gt;）

行本身的 `status` 是**业务字段**，由表格配置决定，不是框架状态。
以示例「订单」为例（配置里的 `order_status` 字典）：

| 状态   | 值          | 说明                         |
| ------ | ----------- | ---------------------------- |
| 待付款 | `pending`   | 初始状态                     |
| 已付款 | `paid`      | 支付回调后                   |
| 已发货 | `shipped`   | 运营点「标记发货」自定义按钮 |
| 已取消 | `cancelled` | 取消订单                     |

| 从     | 事件     | 到        | 说明                                                                   |
| ------ | -------- | --------- | ---------------------------------------------------------------------- |
| 待付款 | 支付成功 | 已付款    | 示例里由数据修改实现                                                   |
| 已付款 | 标记发货 | 已发货    | 自定义按钮 `value=ship`                                                |
| 待付款 | 取消     | 已取消    | —                                                                      |
| 已发货 | 取消     | ❌ 不允许 | 业务规则应在后端校验；**当前示例未做该约束**，需要时在自定义接口里实现 |

> ⚠️ 重要说明：**框架不强制业务状态机的合法性**。
> 状态流转规则属于具体业务，框架只提供「改数据」的能力。
> 如果你的业务有严格的状态机，两种做法：
>
> 1. 在表格配置里关闭「直接编辑 status 字段」，改成自定义按钮 + 自定义接口做校验
> 2. 把状态流转做成独立接口，在 service 层维护状态机

## 5. 请求级状态（token）

```
[未登录] ──POST /api/auth/login──▶ [已登录（token 8h）]
[已登录] ──token 过期/密钥变更──▶ [失效] ──401──▶ 前端清 localStorage → 跳登录页
[已登录] ──主动退登──▶ [未登录]（前端清 token；后端无状态，不做黑名单）
```

| 状态              | 表现                            |
| ----------------- | ------------------------------- |
| 无 token          | 受保护接口 401 `登录状态已失效` |
| token 合法        | 正常访问                        |
| token 过期        | 401，前端自动跳登录             |
| `JWT_SECRET` 变更 | 所有 token 立即失效（验签失败） |

**没有 token 黑名单**：主动退出只是前端删 token，服务端不记录。
要支持「强制下线」需要引入 Redis 黑名单（当前不需要）。

## 6. 前端动态路由加载状态

```
[未加载] ──登录成功 / 带着 token 刷新──▶ [加载中] ──GET /api/routes/my──▶ [已加载]
                                              │
                                              └─失败─▶ [未加载]（守卫下次再试；菜单为空但不白屏）
```

| 状态       | 表现                                             |
| ---------- | ------------------------------------------------ |
| 未加载     | 只能看到静态管理菜单                             |
| 已加载     | 左侧出现业务菜单；刷新业务页面不会掉回首页       |
| 切换子系统 | 整页刷新 → 回到未加载 → 重新加载（保证不串数据） |
